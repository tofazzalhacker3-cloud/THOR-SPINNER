```bash

```

### Steps:
1. **Enter Target** - How many Ultra Rare bundles you want (e.g., 2)
2. **Enter Login Retry** - Default is 3
3. **Wait** - Tool auto-creates accounts and spins until target reached
4. **Done** - Results saved in `THOR SPINNER RESULT` folder
